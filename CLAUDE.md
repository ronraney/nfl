# NFL Best Ball Draft Analyzer — Project Context

## What This Is

A Google Apps Script project that analyzes NFL schedules and ADP data to produce Best Ball draft recommendations. It lives in a Google Spreadsheet and is synced via `clasp`.

**Clasp push command:** `clasp push` (run from WSL, not PowerShell)

## Google Sheets Structure

The spreadsheet has these input sheets (maintained manually):
- **Schedule** — raw PFR schedule data
- **Teams** — team abbreviations, venue type (Dome/Outdoor), division
- **Environment_Combinations** — 24-scenario env lookup table with ceiling rates
- **Position_Multipliers** — venue/primetime multipliers per position
- **Best_Ball_ADP** — player ADP data (Player, Team, POS, AVG, etc.)
- **Vegas_Enhanced_Performances** — 4,489 player performances from 2025 season (imported CSV); columns include `DK Pos`, `Home_Away`, `Venue_Type`, `Primetime`, `Week_Tier`, `DK Top5 Pts`

Output sheets (generated by scripts):
- **Schedule_Enriched** — 272 rows, 47+ columns including `environment_key`, `home_qb_ceiling_rate`, `away_qb_ceiling_rate`, etc.
- **Team_Schedule_Summary** — 32 teams × 5 positions aggregated stats
- **Position_Value_Rankings** — QB/RB/WR/TE ranked by value score
- **Stack_Targets** — all viable 3-player stacks ranked by efficiency
- **Team_Stack_Rankings** — 32 teams ranked by composite stack quality
- **Game_Scores** — 544 rows (272 games × 2 teams), home/away split scores

## Key Architecture Decisions

### Environment Keys
Format: `VenueType_HomeAway_PrimetimeLabel_WeekTier`  
Example: `Dome_Home_Prime_Early`, `Outdoor_Away_Day_Mid`

- `buildEnvironmentKey()` in module_6 always uses `"Home"` (the game context is always from home team's perspective)
- Schedule_Enriched `environment_key` column is always `_Home_` format
- Away rates are derived by replacing `_Home_` with `_Away_` at lookup time

### Home/Away Ceiling Rates (Module 6 Fix)
`buildHomeAwayCeilingRates()` reads `Vegas_Enhanced_Performances` and groups 4,489 performances by `VenueType_HomeAway_PrimetimeLabel_WeekTier` + position. Ceiling rate = `DK Top5 Pts = TRUE` / total performances.

- **No minimum floor** — real 2025 rates are legitimately low (position baseline ~5%)
- `MAX_RATE = 0.60`
- **Fallback hierarchy**: exact group (n≥5) → combined home+away for same base env → position baseline
- Adds 8 columns to Schedule_Enriched: `home_qb_ceiling_rate`, `away_qb_ceiling_rate`, `home_rb_ceiling_rate`, `away_rb_ceiling_rate`, `home_wr_ceiling_rate`, `away_wr_ceiling_rate`, `home_te_ceiling_rate`, `away_te_ceiling_rate`

### Ceiling Rate Percentiles (Module 7)
`buildCeilingRatePercentiles()` returns `{ homePercentiles, awayPercentiles }` — each is a map of `game_id → 0-100 score` for each position. Home and away are ranked **independently** against their own 272 values.

### Schedule Quality
`enrichWithStackData()` uses home/away-specific scores per game:
- If player's team is `home_team` for that game → use `homePercentiles[pos][game_id]`
- If player's team is `away_team` → use `awayPercentiles[pos][game_id]`

`schedule_quality` = sum of 17 game scores. `elite_games_count` = games where score ≥ 70.

### Stack Targets
`buildStackTargets()` generates all 15 combo types per team (QB + 2 from WR1/WR2/WR3/TE1; QB + RB + pass catcher; QB + RB1 + RB2). Filters: all 3 players must have ADP < 200. Returns all valid combos sorted by efficiency (no cap).
